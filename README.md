## 🎧 Core Project — [UNDERSCORE](https://underscoregang.xyz/)

> Meet your server's new favorite music bot — the soundtrack for late-night chats, study sessions, and every hangout in between.

|     | Feature                                                                               |
| --- | ------------------------------------------------------------------------------------- |
| 🔎  | **Search or paste a link** — queue, shuffle, and autoplay                             |
| 🎛️  | **Audio effects** — bass boost, nightcore, karaoke, and more                          |
| 📂  | **Personal playlists** — save them once, play them any session                        |
| 🌙  | **24/7 mode** — the bot stays in your voice channel                                   |
| 🖥️  | **Web dashboard** — pause, skip, change volume, and manage the queue from the browser |
| 🤖  | **Bring your own bot** — custom name, avatar, and prefix                              |

👉 Features, commands, FAQ, and the dashboard: **[underscoregang.xyz](https://underscoregang.xyz/)**
